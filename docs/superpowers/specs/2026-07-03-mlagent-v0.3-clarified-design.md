# MLagent v0.3 — 澄清设计（Clarified Design）

> Date: 2026-07-03 · Branch: `v0.3` · Status: 决策已固化
> 关系：本文件**精炼并取代** [06-26 重设计 spec](./2026-06-26-mlagent-redesign-spec.md) 中的开放问题；二者冲突时**以本文件为准**。spec 中未提及的部分（§10 已定决策、目录结构等）仍有效。
> 依据：[深度调研 memory/ui/plugins](../../research/2026-06-30-research-memory-deepdive.md) + 需求澄清（grilling）。

## 0. 系统定位（澄清后）

一套**完整的记忆系统 + 研发资产显化系统**作底座；其上支撑两个"快"循环：
- **快速按某 SOP 版本重训**（严格确定性：相同输入→完全一致产出）。
- **快速就某方向探索并得出结论**（灵活，不要求结构化；智能体基于目标+经验库注入写代码，人审核）。

**部署模型**：个人主机本地探索/更新记忆 → 会话末 **git push** 到远程服务器 → 开机 **git pull** 同步回来（本地优先，远程持久）。

## 1. 固化的 14 项决策

| # | 决策 | 关键点 |
|---|---|---|
| 1 | **切片 1** = 核心记忆/SOP 闭环（**不含浏览器 UI**）；UI=切片 2 | 先把记忆/SOP 做扎实（最弱、最优先）；UI 后置 |
| 2 | raw_memory 加 **`conclusion` 块** | `{hypothesis, outcome: confirmed\|refuted\|inconclusive, summary, evidence}`，探索末由 explore-train 填；"获取结论"显式化 |
| 3 | **双受众记忆** | (A) 操作层[agent, file-first YAML/MD, **事实源**] + (B) 显化层[人/前端, **派生可重建** SQLite viz-store, FastAPI 服务] |
| 4 | **UI = 两个独立功能** | F1 实时代码审核（manifest 驱动结构+改动+方法/参数）；F2 四看板（SOP 迭代/经验/探索趋势/关键词检索） |
| 5 | 运行日志进 **F2 探索详情** | F1 纯代码审核，不含 console |
| 6 | **distill** | 每 Stop 跑、处理距上次以来的 raw、**无意义则 NOOP**、小会话跳过；异常**只即时写 raw**（conclusion/failure_reason），**不**热路径 distill |
| 7 | **双模式（非对称）** | 探索=**灵活、不要求结构化**（explore-train 松、靠经验注入）；按 SOP 重训=**严格确定性** |
| 8 | **经验库 = 代码风格/规范基座** | 从 SOP 代码逻辑蒸馏规范（如"10 折 CV""卡方选 top-50"）+ 探索积累；注入 explore-train；结构化供 F2 |
| 9 | **SOP 历史 = 模型资产溯源/管理** | 时间点/优化/性能/数据/结果登记；供溯源、复盘、重刷（样本增加等） |
| 10 | **架构 = Claude Code 插件** | sidecar UI（SessionStart 拉起本地 FastAPI+前端）；**非**独立软件 |
| 11 | retrain-from-sop **直读** `skill_library/<sop>/vXXX/` | SOP **不**动态注册为 Claude skill（reloadSkills 桥后置可选） |
| 12 | **git 同步** | 项目记忆+脚本=独立 git 仓；SessionStart `pull` / Stop 一键 `commit+push`；单人多设备；**命名空间后置**；需配 SSH 密钥+非交互 |
| 13 | 显化层形式 = 派生 **SQLite viz-store**（rebuildable）+ FastAPI | 像 FTS 索引一样可重建，永不直接编辑 |
| 14 | SOP→experience 规范蒸馏 | 批准 SOP 时提取代码规范进经验库（复用 skill_extraction 分析） |

**未变（spec §10 锁定）**：FastAPI 后端+独立前端、manifest 驱动脚本面板、不另造命令门禁（靠 CC permission/plan）、3 hooks（SessionStart/PostToolUse/Stop）+ 5 skills（bootstrap/explore-train/distill-experience/instance-to-sop/retrain-from-sop）。

## 2. 精炼架构

### 2.1 记忆系统（双受众）

```text
project_memory/                        ← (A) 操作层 [agent] · 事实源 · YAML/MD
├─ raw_memory/{sessions,explorations,runs,human_notes}/  含 conclusion 块
├─ experience/{lessons,pitfalls,successful_patterns,failed_directions,conventions}/
│     含 confidence · verified · maturity · derived_from（conventions=从SOP蒸馏的代码规范）
├─ skill_library/<sop>/{registry.yaml, vXXX/{SKILL.md, scripts/, sop.yaml, gate, performance.yaml}}
├─ knowledge/{originals,notes,chunks,registry.yaml}
└─ _lineage/  (内联边：evidence-pointers · supersedes · derived_from)

indexes/                               ← (B) 显化层 [人/前端] · 派生可重建
├─ memory.sqlite        FTS（agent 检索）+ 结构化表（viz 查询）
└─ viz.sqlite           派生 viz-store：timeline / performance_trends / lineage_graph / sop_board / experience_board
```
- **(A) 边界**：agent 只写 (A)；(B) 由 `rebuild-viz` 从 (A) 派生（同 FTS，可重建）。
- **conventions**：experience 新增一类（或 successful_pattern 打 tag），存"代码规范/风格"，是 explore-train 的核心注入。

### 2.2 两个快循环（loop 切入探索）

| 节拍 | 切入点 | 人 | 自动 |
|---|---|---|---|
| ① 定方向 | SessionStart→bootstrap（注入 experience/SOP/data understanding） | 说目标+假设 | raw goal/hypothesis；**记忆反哺** |
| ② 写代码 | explore-train（**灵活、不要求结构化**；manifest 可选） | F1 实时审核 | 改动入 raw 草稿 |
| ③ 跑 | explore-train runner | — | tee 日志+metrics+artifacts |
| ④ 得结论 | explore-train 填 raw `conclusion` | 给 verdict | 结构化结论入库 |
| ⑤ 沉淀 | Stop→distill-experience | — | raw→experience（NOOP when 无意义） |
| ⑥ 立 SOP | instance-to-sop（**严格跑通门禁**+人工审批） | 审性能+可复现 | 候选→入 skill_library；蒸馏规范→experience |
| ⑦ 重训 | retrain-from-sop（**直读 SOP、严格确定性**） | 选版本+新数据 | 依规程重训→模型+性能→新 raw |
| ⑧ 同步 | Stop→`mlagent sync`（commit+push）；SessionStart→pull | — | git 同步远程 |

### 2.3 UI（切片 2，本次不实现，仅定契约）
- **F1 实时代码审核**：读当前 `<script>.py`+`<script>.manifest.yaml`+watchfiles 实时渲染结构/改动/方法参数。
- **F2 四看板**（读 viz.sqlite）：SOP 迭代（核心改动总结+性能 delta）/ 经验 / 探索趋势（日期→性能+策略有效性）/ 关键词检索（FTS→定位日期+探索→详情策略+性能，含日志）。

### 2.4 同步子系统（git）
- 项目 `project_memory/`+`runs/`+脚本 = 独立 git 仓，远程=bare repo（你的服务器）/私有 GitHub。
- `mlagent sync`：`git add -A && git commit -m "<ts>" && git push`（一键 push）。
- SessionStart hook：`git pull --ff-only`（开机/会话始同步回来）。
- **密钥/非交互**：插件 `setup` 配置 SSH key 或 credential helper；hook 内 git 用 `GIT_SSH_COMMAND` 指定 key、`GIT_TERMINAL_PROMPT=0` 防交互卡死；push/pull 失败非致命（降级为终端提示，不阻塞 CC）。

## 3. 切片 1 范围 + 任务拆解（TDD）

**切片 1 目标**：核心闭环 `raw(含conclusion) → distill → experience(含规范) → instance-to-sop(严格门禁) → retrain-from-sop(直读) → git 同步`，**不含浏览器 UI**（hook 内 UI start 先降级为终端提示）。验证：CLI + 文件能跑通闭环。

| # | 任务 | 关键产出 | 验证 |
|---|---|---|---|
| **T1** | 插件+包骨架 | `.claude-plugin/{plugin,marketplace}.json`、`bin/mlagent`(Typer)、`mlagent_memory/`、`pyproject`、`hooks/hooks.json`+3 hook 脚本骨架 | `mlagent version`；插件结构合法 |
| **T2** | Schemas(Pydantic) | ProjectProfile、RawMemoryRecord(**+conclusion**)、ExperienceRecord(**+verified/maturity/derived_from**、conventions 类型)、SkillVersion/SOP(**+gate+版本元数据**)、Performance | schema 单测（字段/校验/门禁不变量） |
| **T3** | repo init + status | `project_memory/` 目录树 + profile/registry | `init`/`status` 单测 |
| **T4** | raw/experience 写入 | record-raw（含 conclusion）、add-experience（含规范类）、lineage 字段 | 写入+读回+谱系边单测 |
| **T5** | distill | `mlagent distill`（确定性 Curator：去重/冲突/supersede）+ `distill-experience` SKILL（Claude reflect，产出 INSERT/UPDATE/LINK/SUPERSEDE/NOOP）；Stop hook 触发 | distill 单测（NOOP/INSERT/SUPERSEDE 路径） |
| **T6** | SOP 版本 + instance-to-sop | `skill_library/<sop>/vXXX/`（SKILL.md+scripts+sop.yaml+gate+performance）；instance-to-sop CLI（**跑通测试门禁**+人工审批+**SOP→experience 规范蒸馏**，复用 skill_extraction） | 转换门禁单测（跑不通→不转换；跑通→候选；审批→入库+规范进经验） |
| **T7** | retrain-from-sop | `retrain-from-sop` CLI（**直读** SOP 版本→加载 SKILL/scripts→严格重跑→捕获模型+性能→写 raw）；同名 skill | 直读+结果捕获单测 |
| **T8** | git 同步 | `mlagent sync`（一键 commit+push）、`mlagent pull`、SessionStart pull / Stop push、SSH key/非交互配置（setup）、失败降级 | sync 单测（用本地 bare repo 模拟远程） |
| **T9** | assemble-context | 探索上下文注入（current_prompt→data→experience[含规范]→knowledge→SOP 列表），服务 explore-train | context pack 单测（优先级+规范注入） |
| **T10** | 5 skills + 3 hooks 作者 | bootstrap/explore-train/distill-experience/instance-to-sop/retrain-from-sop SKILL.md；SessionStart/PostToolUse/Stop hook 接线 | hook 烟测（JSON/非阻塞/降级） |
| **T11** | 端到端闭环测试 | init→record-raw(conclusion)→distill→instance-to-sop→retrain→sync 全链 | e2e 测试通过 |

**延后（切片 2+）**：浏览器 UI（F1/F2）、viz-store 的前端服务、动态 skill 注册(reloadSkills)、团队/个人命名空间、知识导入+FTS（若切片1未含）。

## 4. 待办/风险

- **distill 的 LLM 部分**：distill-experience 是 Claude（skill）做反思；确定性 Curator 是 Python（CLI）。二者契约=skill 产出结构化 deltas（JSON），CLI 应用。需定义 delta schema。
- **"严格确定性重训"**：retrain-from-sop 直读 SOP 的 scripts 并执行；确定性依赖脚本本身固定随机种子+环境。gate 记录 env_hash/输入 sha256（调研）以检测漂移。
- **git 同步冲突**：单人多设备偶发分歧 → `git pull --rebase` 或提示人工。MVP 用 `--ff-only` pull + push 失败提示，不自动合并。
- **hook 超时**：git push/pull 放 Stop(~30s)/SessionStart(~60s) 预算内；超时降级。
