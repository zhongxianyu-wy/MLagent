# Triage Labels

| Matt Pocock role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | More product or reproduction information is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for autonomous implementation. |
| `ready-for-human` | `ready-for-human` | Requires a human-only decision or action. |
| `wontfix` | `wontfix` | Deliberately not planned. |

Apply one triage-role label at a time. A state transition replaces the prior role instead of accumulating
conflicting role labels.
